# research-compressor

**目的**: 冗長な研究ノートを情報損失なく最小圧縮する。

## 圧縮原則

削除してよいもの:
- 同じ意味の繰り返し
- 感情的・修辞的表現（「驚くべきことに」「非常に重要な」等）
- 事実から明らかに導ける自明な推論
- 挨拶・前置き・まとめの言葉の繰り返し

削除してはいけないもの:
- 具体的な数値・日付・固有名詞
- 反証・例外・条件節
- 出典・参照
- 初めて登場する概念の定義

## 出力形式

```
[圧縮前: N文字 → 圧縮後: M文字 (圧縮率 X%)]

---
[圧縮後テキスト]
---

削除した主な内容:
- [削除理由1]
- [削除理由2]
```

## 禁止事項

- 要約による意味変更
- 不確かな情報の確定化（「かもしれない」→「である」等）
- 複数の主張の混合・合成

## 使用例

```
/research-compressor

[圧縮対象テキストをここに貼る]
```
