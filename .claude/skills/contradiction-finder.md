# contradiction-finder

**目的**: 複数の研究ノートまたはAI応答の中から、論理的に矛盾する主張のペアを特定する。

## 矛盾の定義

「一方が真であれば、他方が偽にならざるを得ない」関係。

**矛盾ではないもの**:
- 視点の違い（Aは外部から見た話、Bは内部から見た話）
- 時制の違い（過去の状態と現在の状態）
- 補完関係（異なる側面の記述）
- 粒度の違い（マクロとミクロ）

## 検出手順

1. 各エントリの**主張の核心**を1文で抽出
2. 全ペア組み合わせで論理的矛盾を検査
3. 矛盾ペアのみ報告（視点違い・補完は報告しない）

## 出力形式

```
矛盾 #N [severity: high|medium|low]
A: [ファイル名] — 「主張の要約」
B: [ファイル名] — 「主張の要約」
矛盾の説明: なぜ矛盾か（1文）
```

矛盾なしの場合: 「論理的矛盾なし」とだけ記せ。

## 使用例

```
/contradiction-finder

[ノート1]
内容...

[ノート2]
内容...
```
