## 2025-02-28 - PyTorch Native F.gelu Replaces Custom Python Approximations
**Learning:** The codebase previously contained custom Python implementations of `gelu_new` (GPT-2 style) and `gelu_fast` via explicit `torch.tanh` and `torch.pow` operations. I found that PyTorch natively supports these exact approximations via `F.gelu(..., approximate="tanh")`. Benchmarking locally revealed that the native C++ PyTorch implementation is roughly 4x faster (2.5s vs 10.9s/12.0s over 100 iterations) while producing identical results up to float32 precision limits (max diff of ~4.7e-7).
**Action:** Prefer native PyTorch functions with appropriate arguments over manually implementing the math equations in Python, even for mathematically equivalent formulas, to take advantage of low-level C++/CUDA fusion and speedups.
